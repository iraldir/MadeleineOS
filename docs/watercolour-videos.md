Selection is based on creator descriptions, supply lists, and beginner/child teaching context, not a full viewing of every lesson. All 30 videos were public, processed, embeddable, and had no region restrictions or age-rating flags in the API response at verification time. Availability can change.

The category shows five lessons per half-day using the existing drawing rotation and terminal overrides. Each selection aims for at most three lessons per channel and two per theme; the shared picker relaxes caps only if needed to fill the selection. No character/franchise tie-in is required.
